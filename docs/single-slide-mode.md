# Single Slide Mode

Текущий MVP PIP работает в одном однозначном режиме: **«Подобрать один слайд»**. Пользователь выбирает конкретный `contentTypeId`, а результат показывает до шести способов оформить именно этот тип слайда.

Пятый шаг спрашивает «Какой слайд вы хотите подобрать?» и не описывает всю презентацию. Тип слайда сохраняется под существующим machine ID, поэтому старые запросы и feedback sessions остаются совместимыми.

## Правило выдачи

1. Сильные exact matches.
2. Compatible formats только для незаполненных мест.
3. Ограниченный general fallback при нехватке exact и compatible.
4. Hard-incompatible не используется для заполнения выдачи до шести; допускается только для минимального непустого набора из четырёх карточек.

Если найдено шесть сильных exact-кандидатов, Top 6 состоит только из exact. При exactCount ниже четырёх интерфейс сообщает о близких форматах, а Test Mode сохраняет событие `content_type_fallback_shown`.

Режим структуры всей презентации не входит в MVP и описан только в [presentation-structure-mode-roadmap.md](presentation-structure-mode-roadmap.md).
