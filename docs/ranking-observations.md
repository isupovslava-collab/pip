## Потенциальные вопросы для проверки

Следующие пункты являются только направлениями наблюдения и не реализованы как изменения:

- достаточно ли разнообразны первые шесть результатов по типу слайда и композиции;
- понятны ли пользователю причины, по которым конкретный референс оказался в выдаче;
- совпадает ли выбранный Best Reference с наиболее высоко ранжированным вариантом;
- различаются ли ожидания по одинаковому сценарию у разных аудиторий;
- какие параметры запроса чаще связаны с ответом «не найден применимый референс».

Решения об изменении ranking принимаются только после анализа выгруженных данных и повторяемых наблюдений реальных участников.
