# Fresh Discovery v3

Production v3 preserves the historical v2 generator for regression and old sessions while adding six hard controls: exact primary content type, verified direct links, source diversity, composition diversity, screen suitability, and prevention of abstract/template fallbacks. The shortlist has no numeric quota; a short or empty verified response is preferable to filler.

The handoff is deliberately two-step. First the user copies the prompt and sees confirmation. Only then are ChatGPT, Gemini, Perplexity, and Other AI choices shown. Clipboard failure never opens a provider; preview, retry, and manual selection are available. Provider URLs are official home pages and contain no prompt payload.

Feedback schema v6 adds link-quality feedback for all users and composition-diversity feedback in Test Mode. Existing v2 sessions keep their recorded prompt version; migration only supplies null defaults for new fields.
