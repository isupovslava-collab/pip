# Roadmap режимов подбора

## Режим 1 — текущий

**Подобрать один слайд.** Пользователь выбирает один тип слайда и получает несколько вариантов его дизайна. Этот режим реализован в MVP v0.7.1.

## Режим 2 — будущий

**Подобрать структуру всей презентации.** Зафиксирован как отдельная продуктовая возможность для будущего исследования после пользовательских данных.

Режим 2 не реализован, не показан в UI, и его архитектура в Sprint 7.1 не проектировалась.

## Эксперименты после Sprint 8

Следующие возможности остаются только гипотезами и не реализованы:

- ручной эксперимент `Adapt reference to my data`;
- ручная проверка спроса на PPTX Skeleton;
- Black Box reference search;
- расширенные source-backed high-fidelity интерпретации;
- PowerPoint bridge.

Решение о разработке должно приниматься по пользовательским данным, а не автоматически в рамках Verified Source Layer.

## Next Recommended Experiment после Sprint 8.1

Провести пилот на 5–10 пользователях с текущим Fresh Discovery Prompt: измерить долю копирований, оценку полезности и типы задач, для которых внешний поиск действительно дополняет Top 6. Отдельно вручную проверить качество найденных AI-сервисами результатов, корректность URL и конкретных страниц. Только после этих наблюдений решать, нужен ли встроенный API, deep links или дальнейшее расширение approved core.
