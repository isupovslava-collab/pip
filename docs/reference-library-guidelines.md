# Правила библиотеки референсов PIP

## Что такое референс PIP

Референс PIP — синтетический пример структуры одного презентационного решения. Он не копирует чужую презентацию и не хранит внешний контент: объект JSON описывает задачу и применимость, а локальный SVG показывает оригинальную композицию.

## Требования к качеству

- уникальные ID, название, описание и полный набор метаданных;
- только значения из действующей таксономии;
- 3–6 содержательных тегов, 2–4 условия применения и 1–3 ограничения;
- целочисленный Design DNA от 0 до 100, соответствующий композиции;
- `sourceType: "synthetic"`, `sourceLabel: "Демонстрационный референс PIP"`, `sourceUrl: null`;
- локальное SVG-превью 16:9 без внешних ресурсов, растров и реальных логотипов.

## Выбор метаданных

Сценарии, аудитории, цели, стили и типы контента выбираются по фактической применимости решения. Несколько значений допустимы, когда композиция действительно работает в каждом случае. Метаданные не следует расширять только ради статистики покрытия.

## Создание SVG

Все превью используют `viewBox="0 0 1600 900"`, читаемую типографику и дизайн-язык PIP. Композиция должна соответствовать категории референса и заметно отличаться от других решений. Генератор `scripts/generate-library.mjs` создаёт детерминированные SVG на основе данных библиотеки; повторный запуск без изменения входных данных не меняет файлы.

## Gold-quality reference

Gold Reference — это законченный профессиональный слайд, а не схема расположения будущего контента. Он должен проходить следующие критерии:

- один ясный управленческий вывод и реалистичная информационная иерархия;
- правдоподобные подписи, цифры, единицы измерения, статусы и выводы вместо декоративных заглушек;
- композиция, уместная для типа контента: у таблицы есть строки и значения, у dashboard — KPI и динамика, у roadmap — потоки работ, сроки и контрольные точки;
- аккуратная типографика, достаточный контраст, осмысленные акценты и визуальный ритм готового слайда;
- уникальный SVG и заметно отличающийся способ раскрытия содержания;
- точное соответствие одному контрольному запросу и 100% в результатах ранжирования.

Перед включением в Gold Set превью проверяется в карточке результатов, на детальной странице и на Inspiration Board. Отдельно проверяются ширины 375, 768 и 1440 px. Явная привязка Gold References к контрольным запросам хранится в `src/data/goldReferences.ts` и документируется в `docs/gold-reference-map.md`.

## Защита от дубликатов

Не допускаются одинаковые названия, описания, полные комбинации метаданных и SVG-хэши. Частичное совпадение допустимо. Команда `npm run check:duplicates` проверяет точные дубликаты автоматически.

## Добавление референса

1. Добавьте объект в `public/data/references.json` с очередным непрерывным ID.
2. Используйте только ID из `src/types/reference.ts` и `src/data/dictionaries.ts`.
3. Подготовьте оригинальное превью `public/previews/REF-000000.svg` или обновите детерминированный генератор.
4. При необходимости добавьте контрольный запрос в `src/data/controlQueries.ts`.
5. Обновите целевой размер в схеме и проверках, если библиотека расширяется новым Sprint.
6. Обновите отчёт покрытия и выполните полный набор проверок.
