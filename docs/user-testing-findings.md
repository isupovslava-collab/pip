# Наблюдения для следующего продуктового Sprint

Sprint 6 не изменяет ranking, веса или product logic. Ниже зафиксированы потенциальные проблемы, которые требуют подтверждения на пилоте с реальными пользователями:

1. В запросах одного content type могут появляться нерелевантные cover slides.
2. Между разными выдачами подтверждено повторение трёх из шести результатов.
3. Внутри Top-6 недостаточно визуальной вариативности.
4. Для Best Reference нет явного варианта «Нет подходящего результата».
5. В тестовых сессиях отсутствует reference-specific feedback.

Эти пункты являются гипотезами для наблюдения, а не требованиями к немедленному изменению продукта. В Sprint 6 они документированы и намеренно не реализованы.
