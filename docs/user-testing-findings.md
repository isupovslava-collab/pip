# Наблюдения пользовательского тестирования

Пункты ниже были зафиксированы в Sprint 6 и подтверждены пилотом. Sprint 7 реализует точечные исправления без изменения базовых весов и пользовательской таксономии:

1. В запросах одного content type могут появляться нерелевантные cover slides.
2. Между разными выдачами подтверждено повторение трёх из шести результатов.
3. Внутри Top-6 недостаточно визуальной вариативности.
4. Для Best Reference нет явного варианта «Нет подходящего результата».
5. Пользователю не всегда понятны общие объяснения результата.

Статус Sprint 7:

- cover/content mismatch — исправлено content guardrails;
- повторение 3 из 6 — исправлено deterministic diversity reranking, максимум в контрольных парах 1;
- вариативность Top 6 — минимум три композиционных семейства;
- «Нет подходящего варианта» — добавлено в session, JSON/CSV и dashboard;
- объяснения — заменены на 3–5 конкретных причин, fallback обозначается явно.

Meeting v2 и Strategy v2 остаются визуальными гипотезами в review gallery и не входят в production до решения Product Owner.
